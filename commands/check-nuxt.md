---
name: check-nuxt
description: Run a full Nuxt check - build, tests and review, then fix what fails.
---

Run on the current Nuxt project (or $ARGUMENTS):

1. Use skill nuxt-build-fix with `npx nuxi build`.
2. Use skill nuxt-testing to run and fill test gaps.
3. Use agent nuxt-reviewer for review.
4. Report MASHWOOD: what failed, what was fixed, what is left.
