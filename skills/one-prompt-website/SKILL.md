# One Prompt Website

Category: web.

## Steps
1. Extract business, audience, goal and tone from the prompt.
2. fill gaps with sensible defaults and state them.
3. Choose a design direction: palette, type scale, spacing, radius, motion style.
4. Plan sections: hero, proof, features, how it works, pricing or offer, FAQ, call to action, footer.
5. Write real copy, no lorem ipsum.
6. Build mobile-first, semantic HTML, accessible contrast, fast images, subtle motion.
7. Add meta title, description, Open Graph and favicon.
8. Self-review at 375, 768 and 1440 px, then ship as one deployable folder.
