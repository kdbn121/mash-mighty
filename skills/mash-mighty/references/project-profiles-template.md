# Project profiles (template)

Copy this file to `project-profiles.md` in the same folder and fill in your own projects. MASH-mighty applies a profile when the task matches its signals.

| Signals (words, files, folders) | Project | Stack | Rules to always follow |
|---|---|---|---|
| shopapp, `shop/` folder | My Shop App | Next.js, TypeScript, Tailwind | Dark theme; never change prices in code |
| thesis, chapter, reviewer | My Thesis | LaTeX, Python | Harvard referencing; British spelling |

Tips:
- Keep signals specific so the right profile matches.
- Put brand words, banned words and legal rules in the last column.
- Keep private business details out of public repositories.
