# Voiceover Script

Category: media.

## Steps
1. Rewrite for the ear: short sentences, no brackets.
2. Mark pauses and emphasis.
3. Add pronunciation notes for names and Bangla words.
4. Choose voice style, speed and pitch.
5. Export clean text per scene.

## SELECT check
If an installed skill, plugin or connected tool does this job better (real generator, editor, connector), use it and keep these steps as the quality gate.

DONE: Reads naturally at target speed with no stumbles.
