# Music Sync Cuts

Category: media.

## Steps
1. Detect tempo and beat markers.
2. Place cuts on beats, bigger changes on downbeats.
3. Use speed ramps sparingly.
4. Keep the drop for the key moment.
5. Check sync after export.

## SELECT check
If an installed skill, plugin or connected tool does this job better (real generator, editor, connector), use it and keep these steps as the quality gate.

DONE: Cuts land on beats throughout.
Output: MASHWOOD mode (see the mash-mighty skill). First line is the Triad trace.
