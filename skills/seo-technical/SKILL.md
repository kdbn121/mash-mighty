# Seo Technical

Category: web.

## Steps
1. Titles and descriptions unique per page.
2. One H1, logical headings.
3. Sitemap, robots, canonical tags.
4. Structured data for the page type.
5. Fix broken links and slow pages.

## SELECT check
If an installed skill, plugin or connected tool does this job better (real generator, editor, connector), use it and keep these steps as the quality gate.

DONE: Pages indexable with valid structured data.
