# Fine Tune Plan

Category: ai.

## Steps
1. Try prompting and retrieval first.
2. Collect quality examples.
3. Split train and eval.
4. Train small.
5. Compare against baseline.

## SELECT check
If an installed skill, plugin or connected tool does this job better (real generator, editor, connector), use it and keep these steps as the quality gate.

DONE: Clear win over baseline or stop.
