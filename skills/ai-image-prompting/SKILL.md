# Ai Image Prompting

Category: media.

## Steps
1. Subject, action, setting, lighting, lens, style, mood.
2. Add consistency tokens for repeated characters.
3. Give negative or avoid terms where supported.
4. Produce 3 variations.
5. Note aspect ratio and resolution.

## SELECT check
If an installed skill, plugin or connected tool does this job better (real generator, editor, connector), use it and keep these steps as the quality gate.

DONE: Prompts produce on-brief, consistent images.
Output: MASHWOOD mode (see the mash-mighty skill). First line is the Triad trace.
