# Error Handling

Category: engineering.

## Steps
1. Find swallowed errors.
2. Fail fast at boundaries.
3. User-friendly messages, detailed logs.
4. Retries with backoff for transient faults.
5. Tests for failure paths.

If an installed skill, plugin or connected tool does this job better (real generator, editor, connector), use it and keep these steps as the quality gate.
