# Thumbnail Design

Category: media.

## Steps
1. One subject, one emotion, max 4 words.
2. High contrast, readable at 120 px wide.
3. Face or object fills a third of the frame.
4. Make 3 variants for testing.
5. Export 1280x720 under 2 MB.

## SELECT check
If an installed skill, plugin or connected tool does this job better (real generator, editor, connector), use it and keep these steps as the quality gate.

DONE: Text readable at small size, 3 variants ready.
Output: MASHWOOD mode (see the mash-mighty skill). First line is the Triad trace.
