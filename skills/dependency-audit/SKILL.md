# Dependency Audit

Category: engineering.

## Steps
1. List outdated and vulnerable packages.
2. Update patch and minor first.
3. Read changelogs for majors.
4. Run tests.
5. Remove unused packages.

## SELECT check
If an installed skill, plugin or connected tool does this job better (real generator, editor, connector), use it and keep these steps as the quality gate.

DONE: No known vulnerable or unused packages.
