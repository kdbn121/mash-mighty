# LaTeX academic writing patterns

Apply when writing new LaTeX academic writing code.

## Do
- one sentence per line for diffs
- biblatex or natbib consistently
- figures as vector graphics

## Avoid
- undefined references
- overfull boxes
- inconsistent citation keys

## Steps
1. Match the existing project structure and naming.
2. Apply the Do list; check the Avoid list before finishing.
3. Keep functions small and named for intent.
4. Add or update tests with compile check.

DONE: code follows the Do list and none of the Avoid list.
Output: MASHWOOD mode (see the mash-mighty skill). First line is the Triad trace.
