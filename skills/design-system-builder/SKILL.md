# Design System Builder

Category: web.

## Steps
1. Define colour, type, spacing, radius, shadow tokens.
2. Build core components: button, input, card, nav, modal.
3. Document states: hover, focus, disabled, error.
4. Check contrast AA.
5. Export tokens as CSS variables.

## SELECT check
If an installed skill, plugin or connected tool does this job better (real generator, editor, connector), use it and keep these steps as the quality gate.

DONE: Tokens and components consistent and documented.
