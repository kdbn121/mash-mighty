# Video Script

Category: media.

## Steps
1. Define viewer, goal and length.
2. Outline: hook, promise, sections, recap, call to action.
3. Write spoken lines in short sentences.
4. Add visual and B-roll cues per line.
5. Read aloud for timing at about 150 words per minute.

## SELECT check
If an installed skill, plugin or connected tool does this job better (real generator, editor, connector), use it and keep these steps as the quality gate.

DONE: Script fits target length and every line has a visual cue.
