# Podcast To Clips

Category: media.

## Steps
1. Transcribe with timestamps.
2. Find 5 to 10 self-contained moments of 20 to 60 seconds.
3. Trim to start on the strongest line.
4. Add captions, speaker labels and a title card.
5. Write a caption per clip.

## SELECT check
If an installed skill, plugin or connected tool does this job better (real generator, editor, connector), use it and keep these steps as the quality gate.

DONE: Each clip makes sense without context.
Output: MASHWOOD mode (see the mash-mighty skill). First line is the Triad trace.
