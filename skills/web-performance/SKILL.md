# Web Performance

Category: web.

## Steps
1. Measure Core Web Vitals.
2. Fix the largest contentful paint element first.
3. Compress and size images, lazy-load below the fold.
4. Cut unused JavaScript and split bundles.
5. Cache static assets.

## SELECT check
If an installed skill, plugin or connected tool does this job better (real generator, editor, connector), use it and keep these steps as the quality gate.

DONE: LCP under 2.5 s, CLS under 0.1, INP under 200 ms.
Output: MASHWOOD mode (see the mash-mighty skill). First line is the Triad trace.
