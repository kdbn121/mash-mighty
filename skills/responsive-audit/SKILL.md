# Responsive Audit

Category: web.

## Steps
1. Test at 320, 375, 768, 1024, 1440 px.
2. Look for overflow, tiny tap targets, broken grids.
3. Fix with fluid units and breakpoints.
4. Recheck.

## SELECT check
If an installed skill, plugin or connected tool does this job better (real generator, editor, connector), use it and keep these steps as the quality gate.

DONE: No horizontal scroll, tap targets at least 44 px.
Output: MASHWOOD mode (see the mash-mighty skill). First line is the Triad trace.
