# Accessibility Audit

Category: web.

## Steps
1. Keyboard-only walkthrough.
2. Labels, alt text, landmarks.
3. Contrast at least 4.5 to 1.
4. Focus visible and logical.
5. Screen reader check of key flows.

## SELECT check
If an installed skill, plugin or connected tool does this job better (real generator, editor, connector), use it and keep these steps as the quality gate.

DONE: Key flows usable by keyboard and screen reader.
Output: MASHWOOD mode (see the mash-mighty skill). First line is the Triad trace.
