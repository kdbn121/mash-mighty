# Color Grade Guide

Category: media.

## Steps
1. Correct exposure and white balance first.
2. Match shots to a reference.
3. Apply a look subtly.
4. Check skin tones on a vectorscope.
5. Export with the right colour space.

## SELECT check
If an installed skill, plugin or connected tool does this job better (real generator, editor, connector), use it and keep these steps as the quality gate.

DONE: Shots match and skin tones look natural.
Output: MASHWOOD mode (see the mash-mighty skill). First line is the Triad trace.
