# Storyboard

Category: media.

## Steps
1. Split script into shots.
2. For each shot set framing, angle, motion and duration.
3. Write an image prompt per shot with consistent style tokens.
4. Note audio and text overlays.
5. Output as a table.

## SELECT check
If an installed skill, plugin or connected tool does this job better (real generator, editor, connector), use it and keep these steps as the quality gate.

DONE: Each shot has framing, duration and prompt.
Output: MASHWOOD mode (see the mash-mighty skill). First line is the Triad trace.
