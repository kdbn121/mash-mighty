# Text To Video

Category: media.

## Steps
1. Clarify goal, length, aspect ratio (9:16, 1:1, 16:9) and audience.
2. Write a scene-by-scene script with timing per scene.
3. For each scene write a visual prompt for the available image or video generator, plus on-screen text.
4. Write voiceover lines and pick a music mood and tempo.
5. Generate or request clips per scene, keep style and character consistent.
6. Assemble with captions and transitions, export at platform settings.

## SELECT check
If an installed skill, plugin or connected tool does this job better (real generator, editor, connector), use it and keep these steps as the quality gate.
