# Motion Graphics Code

Category: media.

## Steps
1. Pick the tool available (code-based video renderer, CSS or canvas animation).
2. Define scenes and timing as data.
3. Use easing and keep motion purposeful.
4. Render a preview, then final at target fps.
5. Keep assets in one folder.

## SELECT check
If an installed skill, plugin or connected tool does this job better (real generator, editor, connector), use it and keep these steps as the quality gate.

DONE: Renders cleanly at target resolution and fps.
