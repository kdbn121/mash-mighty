# Auto Video Edit

Category: media.

## Steps
1. List the source clips and target length and platform.
2. Detect silences and filler words and cut them (ffmpeg silencedetect or an editor's auto-cut).
3. Keep the strongest takes, order by story: hook, value, payoff, call to action.
4. Add punch-in zooms on key lines and B-roll over jump cuts.
5. Add captions, music ducked under voice, loudness to -14 LUFS.
6. Export and review the first 3 seconds for hook strength.

## SELECT check
If an installed skill, plugin or connected tool does this job better (real generator, editor, connector), use it and keep these steps as the quality gate.

DONE: Runtime on target, no dead air, captions synced, audio normalised.
Output: MASHWOOD mode (see the mash-mighty skill). First line is the Triad trace.
